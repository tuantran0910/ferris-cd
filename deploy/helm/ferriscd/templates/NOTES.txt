1. Verify the control plane is ready:
   kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "ferriscd.fullname" . }}
{{- if .Values.web.enabled }}
   kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "ferriscd.fullname" . }}-web
{{- end }}

2. Configure project-scoped API RBAC (default-deny until rules are added):
{{- if and .Values.rbacPolicy.create (empty .Values.rbacPolicy.rules) }}

{{- else }}
   Policy ConfigMap: {{ .Release.Namespace }}/ferriscd-rbac-cm (key: policy.yaml)

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "ferriscd.fullname" . }} 8080:{{ .Values.service.apiPort }}
   curl http://127.0.0.1:8080/healthz

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "ferriscd.fullname" . }}-web 5173:{{ .Values.web.service.port }}

   Note: `ferriscd-web` serves the static SPA only; in production route `/api` to
   `svc/{{ include "ferriscd.fullname" . }}:{{ .Values.service.apiPort }}` via an Ingress or reverse proxy.
